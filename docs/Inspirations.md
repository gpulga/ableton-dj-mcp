# Inspirations

The artists whose sound shaped what Ableton DJ MCP is tuned for. Their work is
the reference for the grooves, the pacing and the patience the tool aims at.

- **Dixon:** deep, emotional journeys, and DJ sets built as one long story.
- **Guy J:** hypnotic progressive house, long reveals, tracks that evolve by
  adding detail rather than changing direction.
- **Adam Ten:** rolling indie-dance grooves that are simple and still hit.

The [Vision](Vision.md) is the why. This page is the who.
